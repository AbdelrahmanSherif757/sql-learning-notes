# 01 — Introduction to Databases and SQL

## ليه بنستخدم قواعد البيانات؟

ممكن نبدأ بتنظيم بيانات بسيطة في Excel أو Google Sheets. مع زيادة حجم البيانات، والعلاقات بينها، وعدد المستخدمين اللي بيتعاملوا معاها في نفس الوقت، بنحتاج نظام يساعدنا ننظمها ونحافظ على صحتها ونتحكم في الوصول ليها.

هنا بتظهر أهمية قواعد البيانات وأنظمة إدارتها. الاختيار مش بيعتمد على الحجم وحده؛ طبيعة الاستخدام مهمة كمان.

## يعني إيه Database؟

قاعدة البيانات هي مجموعة بيانات متخزنة بشكل منظم يسهّل الوصول ليها والتعامل معاها.

## أنواع قواعد البيانات

### Relational Databases — قواعد البيانات العلائقية

البيانات بتتخزن في جداول (Tables). كل جدول فيه صفوف (Rows) وأعمدة (Columns)، وممكن نربط الجداول ببعض باستخدام مفاتيح (Keys).

مثال: جدول للعملاء وجدول للطلبات، وكل طلب فيه رقم العميل المرتبط بيه.

### NoSQL Databases

اسم بيشمل نماذج مختلفة لتخزين البيانات، منها:

| النوع | الفكرة |
| --- | --- |
| Document | البيانات بتتخزن في مستندات |
| Key-value | كل مفتاح مرتبط بقيمة |
| Graph | البيانات بتتمثل كعُقد وعلاقات |

دي أمثلة، مش قائمة بكل أنواع NoSQL.

## يعني إيه SQL؟

SQL اختصار **Structured Query Language**.

هي لغة بنستخدمها للتعامل مع قواعد البيانات العلائقية: نسترجع بيانات، نضيفها، نعدّلها، نحذفها، وكمان نعرّف الجداول ونتحكم في الصلاحيات.

SQL لغة، وليست قاعدة بيانات أو برنامج إدارة قواعد بيانات.

## يعني إيه RDBMS؟

اختصار **Relational Database Management System**، يعني نظام إدارة قواعد البيانات العلائقية.

أمثلة: PostgreSQL وMySQL وMicrosoft SQL Server.

## عمليات CRUD

| العملية | معناها | الأمر المستخدم مع البيانات |
| --- | --- | --- |
| Create | إضافة بيانات جديدة | INSERT |
| Read | قراءة البيانات | SELECT |
| Update | تعديل بيانات موجودة | UPDATE |
| Delete | حذف بيانات | DELETE |

ملحوظة: Create في CRUD معناها إضافة سجل، أما `CREATE TABLE` فهو أمر لإنشاء جدول.
