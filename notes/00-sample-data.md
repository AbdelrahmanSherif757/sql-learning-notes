# بيانات الأمثلة المشتركة

## مصدر البيانات وحدود المعلومات

الصفوف دي من صور الجدول المستخدم في مذاكرتي. الصور بتعرض الأعمدة والبيانات، لكنها مش بتعرض اسم الجدول أو أنواع الأعمدة أو القيود؛ لذلك هنستخدم `employees` كاسم افتراضي في الشرح. لو الاسم عندك مختلف، استبدله في الاستعلامات.

الصورة وحدها مش بتثبت إن `id` عليه قيد PRIMARY KEY أو إن أعمدة الأسماء عليها NOT NULL. ما افترضناش إن قاعدة بياناتك فيها أقسام أو علاقات إضافية.

## تجهيز نسخة تدريبية — اختياري

لو الجدول عندك جاهز، ابدأ الاستعلامات مباشرة ولا تعيد إدخال البيانات. الكود التالي لإعادة إنشاء مثال مكافئ في قاعدة تدريب جديدة فقط؛ الأنواع والقيود اختيارات تعليمية، وليست وصفًا مؤكّدًا لتصميم جدولك الأصلي.

```sql
CREATE TABLE employees (
    id INTEGER PRIMARY KEY,
    first_name TEXT,
    last_name TEXT,
    salary NUMERIC(10, 2)
);

INSERT INTO employees (id, first_name, last_name, salary)
VALUES
```

## ملاحظات

- كل نتائج دروس SELECT وWHERE وIN وNULL والترتيب المنطقي محسوبة من الصفوف دي.
- بنضيف `ORDER BY id` عشان ترتيب النتيجة يبقى ثابتًا.
- النتائج الحسابية معروضة بمنزلتين للتبسيط؛ البرنامج ممكن يعرض منازل أكتر.
- درس العلاقات فيه جداول تعليمية مستقلة، مش موجودة في الصور ولا مطلوبة لتشغيل أمثلة الموظفين.
